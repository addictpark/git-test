# 🏠 프로젝트 대시보드

> [!info] 이 대시보드는 `프로젝트/` 폴더의 노트들을 자동으로 집계합니다. 새 프로젝트를 추가하면 바로 반영됩니다. (Dataview 플러그인 필요 — [[사용법]] 참고)

## 📌 전체 요약

```dataview
TABLE WITHOUT ID
  length(rows) AS "전체 프로젝트",
  length(filter(rows, (r) => r.상태 = "진행중")) AS "진행중",
  length(filter(rows, (r) => r.상태 = "완료")) AS "완료",
  length(filter(rows, (r) => r.상태 = "지연")) AS "지연",
  round(average(rows.진행률)) + "%" AS "평균 진행률"
FROM #project
GROUP BY "요약"
```

## 🔥 진행 중인 프로젝트

```dataview
TABLE WITHOUT ID
  file.link AS "프로젝트",
  담당자 AS "담당자",
  우선순위 AS "우선순위",
  마감일 AS "마감일",
  (마감일 - date(today)).days AS "남은 일수",
  "<progress value='" + 진행률 + "' max='100'></progress> " + 진행률 + "%" AS "진행률"
FROM #project
WHERE 상태 = "진행중" OR 상태 = "지연"
SORT 마감일 ASC
```

## ⚠️ 마감 초과 (미완료)

```dataview
TABLE WITHOUT ID
  file.link AS "프로젝트",
  담당자 AS "담당자",
  상태 AS "상태",
  마감일 AS "마감일",
  (date(today) - 마감일).days AS "초과 일수"
FROM #project
WHERE 상태 != "완료" AND 마감일 < date(today)
SORT 마감일 ASC
```

## ⏰ 마감 임박 (7일 이내)

```dataview
TABLE WITHOUT ID
  file.link AS "프로젝트",
  담당자 AS "담당자",
  상태 AS "상태",
  마감일 AS "마감일",
  (마감일 - date(today)).days AS "남은 일수"
FROM #project
WHERE 상태 != "완료" AND 마감일 >= date(today) AND 마감일 <= (date(today) + dur(7 days))
SORT 마감일 ASC
```

## 📋 전체 프로젝트 목록

```dataview
TABLE WITHOUT ID
  file.link AS "프로젝트",
  상태 AS "상태",
  분류 AS "분류",
  담당자 AS "담당자",
  우선순위 AS "우선순위",
  시작일 AS "시작일",
  마감일 AS "마감일",
  진행률 + "%" AS "진행률"
FROM #project
SORT 마감일 ASC
```

## 👤 담당자별 프로젝트

```dataview
TABLE WITHOUT ID
  key AS "담당자",
  length(rows) AS "프로젝트 수",
  rows.file.link AS "프로젝트"
FROM #project
GROUP BY 담당자
```

## ✅ 남은 작업 모아보기

> 각 프로젝트 노트의 미완료 체크박스가 프로젝트별로 묶여서 표시됩니다.

```dataview
TASK
FROM #project
WHERE !completed
GROUP BY file.link
```
