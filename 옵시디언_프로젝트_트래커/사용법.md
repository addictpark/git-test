# 📖 사용법

옵시디언용 프로젝트 트래커입니다. 엑셀 버전과 같은 개념(상태·우선순위·담당자·마감일·진행률)을 옵시디언 방식으로 옮겼습니다.

## 핵심 구조

**"프로젝트 하나 = 노트 하나"** 입니다. 노트 상단의 속성(프론트매터)이 엑셀의 한 행에 해당하고, 노트 본문의 체크박스가 그 프로젝트의 작업 목록입니다. [[🏠 대시보드]]가 모든 프로젝트 노트의 속성을 자동으로 읽어 집계합니다.

```
옵시디언_프로젝트_트래커/
├── 🏠 대시보드.md      ← 자동 집계 (엑셀의 대시보드 시트)
├── 📌 칸반 보드.md      ← 상태별 보드 (선택, Kanban 플러그인 필요)
├── 사용법.md
├── 프로젝트/            ← 프로젝트 노트들 (엑셀의 프로젝트+작업+상세 시트)
└── 템플릿/
    └── 프로젝트 템플릿.md
```

## 처음 설정 (1회)

1. 이 폴더 전체를 사용 중인 볼트(vault) 안에 복사합니다. (또는 이 폴더 자체를 새 볼트로 열어도 됩니다)
2. **Dataview 플러그인 설치**: 설정 → 커뮤니티 플러그인 → 탐색 → "Dataview" 검색 → 설치 후 활성화. 대시보드가 동작하려면 필수입니다.
3. (선택) **Kanban 플러그인**: 같은 방법으로 "Kanban"을 설치하면 [[📌 칸반 보드]]를 드래그 앤 드롭 보드로 쓸 수 있습니다.
4. (선택) 설정 → 템플릿(코어 플러그인)에서 템플릿 폴더를 `옵시디언_프로젝트_트래커/템플릿`으로 지정하면 새 노트에 템플릿을 바로 삽입할 수 있습니다.

## 새 프로젝트 추가

1. `프로젝트/` 폴더에 새 노트를 만듭니다. 이름은 `PRJ-007 프로젝트명` 형식을 추천합니다.
2. [[프로젝트 템플릿]] 내용을 붙여넣고(또는 템플릿 삽입 명령 사용) 속성을 채웁니다.
3. 끝입니다. 대시보드에 자동으로 나타납니다.

## 속성 규칙

| 속성 | 값 |
|---|---|
| `tags` | `project` 태그가 있어야 대시보드에 집계됩니다 |
| `상태` | 계획 / 진행중 / 완료 / 보류 / 지연 |
| `우선순위` | 높음 / 중간 / 낮음 |
| `시작일`, `마감일` | `YYYY-MM-DD` 형식 (날짜 선택기로 입력 가능) |
| `진행률` | 0~100 숫자만 입력 (% 기호 없이) |

## 작업(태스크) 관리

프로젝트 노트의 `## ✅ 작업` 섹션에 체크박스로 관리합니다.

```markdown
- [ ] 메인 페이지 퍼블리싱 [담당:: 김철수] [마감:: 2026-07-18]
```

- 체크하면 완료 처리되고, 대시보드의 "남은 작업 모아보기"에서 사라집니다.
- `[담당:: ]`, `[마감:: ]` 같은 인라인 필드는 선택 사항입니다.

## 엑셀 버전과의 대응 관계

| 엑셀 | 옵시디언 |
|---|---|
| 대시보드 시트 | [[🏠 대시보드]] |
| 프로젝트 시트 (목록) | 대시보드의 "전체 프로젝트 목록" |
| 작업 시트 | 각 프로젝트 노트의 체크박스 |
| 프로젝트 상세 시트 | 프로젝트 노트 자체 (열면 그게 상세 화면) |
| 간트차트 | 칸반 보드로 대체 (아래 참고) |
| 설정 시트 (드롭다운) | 속성값 규칙 (위 표) |

## 참고

- **간트차트**: 옵시디언 기본 기능에는 없습니다. 마크다운 코드블록으로 간트를 그리는 Mermaid(기본 내장)를 쓸 수는 있지만 수동 갱신이라, 상태 흐름 관리는 칸반 보드를 추천합니다.
- **Obsidian 1.9+ 의 코어 기능 "Bases"** 를 쓰면 플러그인 없이도 프로젝트 노트들을 표 형태로 볼 수 있습니다. 같은 속성 구조를 그대로 읽으므로 이 트래커와 호환됩니다.
- 상태/우선순위 값은 자유롭게 바꿔도 되지만, 대시보드 쿼리 안의 문자열("진행중", "완료" 등)도 같이 바꿔야 합니다.
